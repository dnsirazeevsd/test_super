### Raw-source removal caveat

`assets/source/` was removed in its own commit as explicitly requested. It is **not an input to `npm run build`**, which uses the committed generated images and image manifest. However, it is **not globally unreferenced**: README, the image-needed report, content instructions and `scripts/optimize-images.mjs` refer to these originals. Those protected references and the image manifest were deliberately left unchanged.

Before running `npm run optimize-images`, restore the originals from the owner's local copy or Git history at the baseline commit. Do not run it with the source folder absent: it can overwrite `src/data/image-manifest.json` with an empty manifest. The optimizer was not run during cleanup. Existing public images, fonts, favicons, manifest and OG image are untouched.
